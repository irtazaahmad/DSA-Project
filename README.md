# 🏦 Bank Management & ATM System (C++)

## 📌 Introduction
This project is a **Bank Management and ATM System** developed in **C++**.  
It is a console-based application that simulates real-world banking operations, including account management and ATM transactions.

The system is designed with two main modules:

- 👨‍💼 **Admin Panel**
- 💳 **ATM System (User Panel)**

This project demonstrates the use of **Data Structures, File Handling, and Object-Oriented Programming (OOP)** concepts.

## 🚀 Features

## 👨‍💼 Admin Panel
Admin has full control over the system:

- 🆕 Create new bank accounts  
- 📋 View all account details  
- 🔍 Search for a specific account  
- 📜 View transaction logs  
- ❌ Delete accounts  
- 🔐 Secure admin login  

---

## 💳 ATM System (User Panel)
Bank customers can:

- 🔐 Login to their account  
- 💰 Check account balance  
- ➕ Deposit money  
- ➖ Withdraw money  

---

## 🔐 Authentication System
- Separate login system for **Admin** and **Users**
- Ensures secure access to functionalities

---

## 📂 Data Management
- Stores account data in:
  - `accounts_data.txt`
- Stores transaction logs in:
  - `accounts_logs_data.txt`
- Uses **Binary Search Tree (BST)** for efficient searching and management
